Regles de traduction strictes :
- MAPPING LOAD              -> CREATE OR REPLACE TEMP TABLE
- RESIDENT <table>          -> FROM <table>
- ApplyMap('Map', key, def) -> COALESCE((SELECT val FROM Map WHERE k=key), def)
- NOT Exists(Key, field)    -> NOT EXISTS (SELECT 1 FROM table WHERE col=field)
- Concatenation &           -> ||
- left(str, n)              -> SUBSTR(str, 1, n)
- right(str, n)             -> RIGHT(str, n)
- mid(str, pos)             -> SUBSTR(str, pos)
- MAXSTRING()               -> MAX()
- wildmatch(f,'a','b')>0   -> f IN ('a','b')
- if(cond, a, b)            -> CASE WHEN cond THEN a ELSE b END
- Rowno()                   -> ROW_NUMBER() OVER ()

Contraintes DuckDB :
- Pas de UPDATE sur TEMP TABLE -> recreer avec SELECT
- CREATE OR REPLACE TABLE pour les tables finales
- CREATE OR REPLACE TEMP TABLE pour les intermediaires
- Index non supportes sur TEMP TABLE -> les omettre
- SUBSTR(str, -n) retourne vide en DuckDB -> utiliser RIGHT(str, n)
- Pour les periodes SAP : LPAD(CAST(CAST(PERIO AS INTEGER) AS VARCHAR), 2, '0')
- Toutes les colonnes sources sont VARCHAR. Toujours caster explicitement avant toute operation arithmetique ou numerique : CAST(col AS DOUBLE), etc.
- Les dates sources sont au format M/D/YYYY (ex: '4/4/2024'). Les valeurs manquantes sont '-'. Toujours utiliser TRY_STRPTIME (jamais strptime ni CAST AS DATE) : TRY_STRPTIME(col, '%m/%d/%Y').
- AddYears(col, n) -> TRY_STRPTIME(col, '%m/%d/%Y') + INTERVAL (n) YEAR
- AddMonths(col, n) -> TRY_STRPTIME(col, '%m/%d/%Y') + INTERVAL (n) MONTH
- Floor(col) -> FLOOR(CAST(col AS DOUBLE))

    Count(DISTINCT InstrumentID)        AS [Nb Instruments Trades],

    Max([Date Transaction])             AS [Derniere Transaction]

[KPI_Port_Client]:
LOAD
    PortefeuilleID,
    [Total Investi (EUR)],
    [Total Dividendes (EUR)]
Resident [KPI_Portefeuilles];

JOIN ([KPI_Port_Client])
LOAD
    PortefeuilleID,
    ClientID
Resident [Dim_Portefeuilles];

// Step 2 : aggregate by ClientID
[KPI_Clients]:
LOAD
    ClientID,
    Sum([Total Investi (EUR)])          AS [Total Investi Client (EUR)],

    Count(DISTINCT PortefeuilleID)      AS [Nb Portefeuilles]
Resident [KPI_Port_Client]
Group By ClientID;

    Severite,
    Statut                               AS [Statut Alerte],
    Description                          AS [Description Alerte],
    Num#(ValeurMesure)                   AS [Valeur Mesurée],
    Num#(SeuilAlerte)                    AS [Seuil Alerte],
    Date#(DateResolution, 'YYYY-MM-DD')  AS [Date Résolution],
    If(Statut='Résolue',
        Date#(DateResolution,'YYYY-MM-DD') - Date#(DateAlerte,'YYYY-MM-DD'),
        Null()) AS [Délai Résolution (jours)]
FROM [$(vDataPath)fact_alertes_risque.csv]
(txt, codepage is 28591, embedded labels, delimiter is ',', msq);

];

Resident [Dim_Instruments];

Severite, Priorité Numérique

// ============================================================
// SECTION 4 : TABLE MAÎTRE DE DATES (Master Calendar)
// ============================================================
// Consolidation de toutes les dates des tables de faits

[TempDates]:
LOAD DISTINCT [Date Transaction] AS TmpDate  Resident [Fact_Transactions] ;
CONCATENATE([TempDates])
LOAD DISTINCT [Date Snapshot] AS TmpDate Resident [Fact_Positions] ;
CONCATENATE([TempDates])
LOAD DISTINCT [Date Performance] AS TmpDate Resident [Fact_Performances] ;
CONCATENATE([TempDates])
LOAD DISTINCT [Date Alerte] AS TmpDate  Resident [Fact_Alertes] ;

LET vMinDate = Num(Peek('TmpDate', 0, 'TempDates'));
LET vMaxDate = Num(Today());

[MasterCalendar]:
LOAD
    Date(TmpDate)               AS [Date],
    Year(TmpDate)               AS [Année],
    Month(TmpDate)              AS [Mois Num],
    MonthName(TmpDate)          AS [Mois],
    'T' & Ceil(Month(TmpDate)/3) AS [Trimestre Label],
    Week(TmpDate)               AS [Semaine ISO],
    WeekDay(TmpDate)            AS [Jour Semaine Num],
    DayName(TmpDate)            AS [Jour Semaine Nom],
    'S' & If(Month(TmpDate) <= 6, 1, 2) AS [Semestre Label],
    Year(TmpDate) & '-' & Right('0' & Month(TmpDate), 2) AS [AAAA-MM]
Resident [TempDates];

Drop Table TempDates;

    Min([Date Transaction])             AS [Première Transaction],
    Max([Date Transaction])             AS [Dernière Transaction]
Resident [Fact_Transactions]
Group By PortefeuilleID;
